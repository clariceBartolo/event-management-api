# Event Management API

This project is a RESTful API for managing events, attendees, venues, ticket bookings, and multimedia assets.
It is built using Python and FastAPI and uses MongoDB Atlas for the database.

## Environment Setup

1. Created a project folder `databse`.
2. Created a Python virtual environment:
   - macOS/Linux: `python3 -m venv .venv` & `source .venv/bin/activate`
3. Installed required dependencies
4. Generated `requirements.txt`
